---
name: Incremental profile rescans
description: Product rule for refreshing student profiles from newly added documents and links.
---

When a student rescans their profile, process only the newly supplied or replaced documents and links. Merge supported findings into the existing profile; do not restart onboarding or reset goals, answers, quests, or XP. Student-entered planning choices remain authoritative over document extraction.

**Why:** Students need to keep their existing Trojan Arc setup while adding updated source material.

**How to apply:** Any future rescan changes should preserve current user-owned settings and progress; replacement-source removal requires source-level provenance so unrelated profile facts are not lost.
